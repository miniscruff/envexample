# Changelog
All notable changes to this project will be documented in this file.

## v0.4.0 on 2026-11-07

### Removed

* [#73](https://github.com/miniscruff/envexample/issues/73) Homebrew tap, install with `go get -tool github.com/miniscruff/envexample@latest` instead. Existing Homebrew installs stay on v0.3.1 with a deprecation warning

### Fixed

* [#77](https://github.com/miniscruff/envexample/issues/77) `go install` and `go tool` builds report their version instead of `dev`

## v0.3.1 on 2026-11-07

### Fixed

* [#74](https://github.com/miniscruff/envexample/issues/74) Relative `-pkg` paths such as `.`, now the default, write the full example again, and a config struct that is not found is an error instead of an empty example

## v0.3.0 on 2026-11-07

### Changed

* [#72](https://github.com/miniscruff/envexample/issues/72) Modernize to Go 1.26 and gengo v2, so installing envexample now requires Go 1.26 or newer

### Fixed

* [#69](https://github.com/miniscruff/envexample/issues/69) Struct fields with `env:"-"` are no longer documented
* [#70](https://github.com/miniscruff/envexample/issues/70) Structs without env fields of their own, such as structs only grouping other structs, are no longer written as an empty comment block

## v0.2.0 on 2026-04-16

* [#60](https://github.com/miniscruff/envexample/issues/60) Fields with a dash name override are now ignored
